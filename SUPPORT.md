# Support

Need help with the FeedbackKit Vapor SDK? Here's how to get support.

## Documentation

The getting-started guide in this package is [docs/getting-started.md](docs/getting-started.md). The website page is [Vapor SDK](https://getfeedbackkit.com/docs/vapor) once that server build is deployed. The public mirror is [SwiftlyFeedbackKit-Vapor-SDK](https://github.com/Swiftly-Developed/SwiftlyFeedbackKit-Vapor-SDK). Pin `from: "3.0.0"`. Tags `1.1.1` and `2.0.0` do not include this API.

## Report an Issue

Found a bug or have a feature request? Open an issue on GitHub:

[GitHub Issues](https://github.com/Swiftly-Developed/SwiftlyFeedbackKit-Vapor-SDK/issues)

## Contact Us

For general questions or support inquiries:

**Email:** info@swiftly-developed.com

We typically respond within 1-2 business days.
